# Agent Environment

This repository is a GitOps repository for automating OrcAI jobs across OSS projects. An AI agent operating in this repo should understand the following tools and conventions.

## Tools

### orcai CLI

`orcai` is the primary tool for this repository. It is a .NET CLI tool that creates and manages bulk GitHub issues, projects, and Copilot assignments across multiple repositories.

- Installed as a local .NET tool via `dotnet-tools.json`
- Invoked as `dotnet orcai <command>`
- Full CLI reference: <https://github.com/dburriss/orcai/blob/main/docs/cli-reference.md>

### mise

`mise` is the task runner and tool version manager used in this repository.

- Installed globally; verify with `mise --version`
- Task definitions live in `mise.toml`
- Run tasks with `mise run <task-name>` or `mise <task-name>`

## Folder Structure

```text
.github/
  workflows/
    orcai-verify.yml    # runs on pull_request targeting jobs/
    orcai-run.yml       # runs on push to main touching jobs/
.agent/
  orcai/
    SKILL.md            # companion agent skill for orcai workflows
jobs/
  <name>/
    <name>.yml          # orcai job config
    <name>.md           # issue template (referenced by the YAML)
    <name>.lock.json    # generated by `orcai run`, committed back automatically
plans/
  *.md                  # planning documents for repository setup
mise.toml               # tool versions and task definitions
dotnet-tools.json       # local .NET tool manifest (includes OrcAI.Tool)
AGENT.md                # this file
README.md               # repository overview and usage instructions
```

## Common Tasks

| Task | Command |
|------|---------|
| Restore tools | `mise run install` |
| Validate job configs | `mise run validate` |
| Run all jobs | `mise run run-jobs` |

## Secrets (CI)

The following repository secrets must be configured for CI workflows to authenticate with GitHub:

| Secret | Description |
|--------|-------------|
| `ORCAI_APP_ID` | GitHub App numeric ID |
| `ORCAI_APP_INSTALLATION_ID` | Installation ID for the target organisation |
| `ORCAI_APP_PRIVATE_KEY` | Full PEM content of the App private key |

See `README.md` for the full GitHub App setup guide.
